# Incident report

- Scope, collection window, affected assets, and reported incident classification
- Timeline with original timestamps, timezones, and evidence IDs
- Supported observations, alternate explanations, and unresolved questions
- Recommended response and follow-up observations for the incident owner

Use confirmed, suspected, benign, simulation only, or inconclusive according
to the evidence. Present chronology with unresolved ordering where clocks or
offsets disagree. Keep response recommendations advisory.
