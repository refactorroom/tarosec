# Security policy

Report vulnerabilities in Tarosec's skills, scripts or schemas privately via
GitHub Security Advisories on this repository. Please do not open a public issue.

In scope: a skill instruction that leads an agent to exceed authorization, to
follow instructions in evidence, or to leak secrets; helper scripts that write
outside their target, execute input, or misclassify in a way that hides a gap.

Tarosec skills are guidance for AI agents, not an enforcement layer. Use host
permissions and network isolation for hard boundaries.
