Audit

Review a local project for security risks in source code, dependencies, CI/CD, and agent integrations.

All workflowsAuditRedBluePurpleSimulate

What to provide

Provide a local checkout and the areas you want reviewed. For dependency triage, include a lockfile and any advisory or scanner report you already have.

Modes

quick
Triage likely risks in exposed and privileged paths.
deep
Trace trust boundaries and explain coverage gaps.
dependencies
Compare reported issues with resolved versions.
agents
Review agent skills, hooks, prompts, and MCP integrations.
verify
Recheck existing findings against current source.

Workflow

  1. Identify the assets and trust boundaries in scope.
  2. Trace suspected issues to code and distinguish verified findings from potential risks.
  3. Prioritize findings and cite the supporting file and line, impact, and remediation.

Example agent request

$tarosec audit ./project
Review configuration and authentication. Cite file and line evidence and report coverage gaps.

What to expect

A prioritized report with evidence, remediation guidance, and unverified areas. Secrets should be redacted from the report.
