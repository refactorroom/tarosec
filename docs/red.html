Install Tarosec

Red

Map assets and review existing assessment evidence within a defined scope.

All workflowsAuditRedBluePurpleSimulate

What to provide

Provide the scope or engagement record, an asset inventory, and any prior observations or scanner reports.

Modes

recon
Summarize assets and exposed interfaces from supplied evidence.
scan
Review an existing scan and its metadata.
simulate
Interpret observations from a benign fixture.
bounty
Draft a sanitized report using the supplied program policy.
validate
Check whether evidence supports an existing finding.

Workflow

  1. Identify which assets are in scope, excluded, or unverified.
  2. Compare assertions with supplied records and note gaps.
  3. Summarize the assessment with source references and scope limits.

Example agent request

$tarosec red
Review my asset inventory and engagement record. List in-scope, excluded, and unverified assets.

What to expect

An offline assessment based on the supplied evidence. A scope record by itself does not grant permission to contact a target.
