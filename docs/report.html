Report

Consolidate supplied security records, trace findings to evidence, and surface verification gaps.

  • $tarosec report ./cases prepares a summary.
  • $tarosec-report technical ./cases prepares a developer report.
  • $tarosec-report coverage ./exercises reviews recorded detection outcomes.

The Python helper exports Markdown, structured JSON, and an evidence manifest locally.
