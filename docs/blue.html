Blue

Investigate logs and alerts, identify evidence gaps, and improve detection rules.

All workflowsAuditRedBluePurpleSimulateReport

What to provide

Provide sanitized logs, alert exports, or a saved case. Include the relevant time window and time zone if available.

Modes

hunt
Search supplied telemetry using a defined hypothesis.
triage
Classify an alert or event cluster.
logs
Normalize logs and identify gaps and duplicates.
detect
Draft or tune a detection rule with test cases.
verify
Check a control or claim against supplied exports.
monitor
Review an existing monitoring setup for coverage gaps.

Workflow

  1. Describe the available sources and time coverage.
  2. Build a timeline and test alternative explanations.
  3. Report classification, supporting evidence, and what would change the conclusion.

Example agent request

$tarosec blue ./logs
Triage the alerts. Compare them with the change records and explain any timing uncertainty.

What to expect

A timeline and evidence-based assessment. A missing event remains a gap in evidence when collection coverage is unknown.
