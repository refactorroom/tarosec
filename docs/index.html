Install Tarosec

GitHub release v0.2.0 includes seven skills, including Report.

Run these commands from your project directory. You need Node.js for installation and Python 3.10+ to run the included helpers.

Start a new session in your coding agent and enter $tarosec ./project to begin.

Add skills from GitHub
npx skills add refactorroom/tarosec
Install the npm package
npm install tarosec@0.1.0

The npm release is currently v0.1.0 and downloads six skill directories to node_modules/tarosec/skills/.

Sync the npm copy into Codex
npx skills@1.9.0 experimental_sync --copy --agent codex

If you chose npm, run this next to copy the skills from your installed dependencies into this project's Codex skill directory. The command uses Skills CLI version 1.9.0.
