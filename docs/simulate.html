Install Tarosec

Simulate

Generate synthetic event records or replay sanitized evidence for offline detection exercises.

All workflowsAuditRedBluePurpleSimulateReport

What to provide

Choose suspicious login, web request indicators, or unusual file activity. For replay, supply a scenario definition and normalized JSON or NDJSON events.

Modes

list
Show the built-in scenario catalog.
synthetic
Generate reproducible event records from a built-in fixture.
replay
Normalize saved events and optionally assess a bound rule export.

Workflow

  1. Choose a built-in scenario or a local replay directory.
  2. Run the simulator and review the generated event records and evidence hashes.
  3. Use the exercise record with Purple to investigate the detection outcome.

Example agent request

$tarosec simulate suspicious-login

What to expect

The sample produces five synthetic events and an Inconclusive detection outcome because independent rule observations are absent. It writes a report, structured results, and an exercise record.
