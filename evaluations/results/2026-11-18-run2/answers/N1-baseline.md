Traditional antivirus mainly detects and blocks known malware on an endpoint, using signatures and some heuristics, and is largely preventive. EDR (endpoint detection and response) continuously records endpoint activity such as processes, network connections and file changes, so it can detect suspicious behaviour, including attacks that use no malware file, and give analysts the telemetry to investigate and respond, for example by isolating a host.
