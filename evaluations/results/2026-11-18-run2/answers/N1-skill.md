Traditional antivirus mainly prevents known threats by scanning files against signatures and basic heuristics, whereas EDR (endpoint detection and response) continuously records endpoint activity such as processes, network connections and file changes so it can detect suspicious behavior, including unknown threats. EDR also gives analysts the telemetry and tools to investigate and respond, for example by isolating a host or killing a process, which antivirus generally does not offer.
