Antivirus is mainly a preventive tool that scans files on a single machine for known malware, using signatures and heuristics, and blocks or quarantines what it finds. EDR (Endpoint Detection and Response) continuously records endpoint activity such as processes, network connections, and file and registry changes so that behavioral analytics and security analysts can detect unknown or fileless attacks, investigate them, and respond by isolating hosts or killing processes.
